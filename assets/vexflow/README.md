# VexFlow 5.0.0

`vexflow.js` is the unmodified `build/cjs/vexflow-bravura.js` browser bundle from the pinned npm dependency. It includes Bravura and Academico fonts, so full notation does not require a CDN or an internet connection. VexFlow uses the MIT license in `LICENSE`; font notices are preserved alongside it.

Source: https://github.com/vexflow/vexflow/tree/5.0.0

To refresh after an intentional dependency update, copy `node_modules/vexflow/build/cjs/vexflow-bravura.js` here as `vexflow.js`, retaining the applicable library and font licenses.
