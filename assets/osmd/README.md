# OpenSheetMusicDisplay 2.2.1

`opensheetmusicdisplay.min.js` is the unmodified browser bundle from the pinned `opensheetmusicdisplay` npm package. It loads locally on first use of an imported MusicXML score. No score is sent to an external rendering service.

Source: https://github.com/opensheetmusicdisplay/opensheetmusicdisplay

The BSD-3-Clause license is reproduced in `LICENSE`. The bundle includes its dependency license notices. To update intentionally, install the chosen package version and copy `node_modules/opensheetmusicdisplay/build/opensheetmusicdisplay.min.js`, retaining the relevant licenses.
